# 验收清单（8 条，逐条打勾才算通过）

> 验收环境：各自 PC 本地起全栈（后端 :3001 + 前端 :5173，前端 VITE_API_BASE 指向本地后端）。

- [ ] **1. 新增**：填写表单（标题+模块+严重度）提交 → "待处理"列出现新卡片，统计条总数 +1
- [ ] **2. 流转**：点卡片上的"开始处理" → 卡片移到"处理中"列；**刷新浏览器后仍在处理中列**
- [ ] **3. 完成**：点"标记解决" → 移到"已解决"列；刷新后保持
- [ ] **4. 删除**：点"删除"并确认 → 卡片消失；刷新后仍消失
- [ ] **5. 校验**：标题为空提交 → 页面出现错误提示，且不新增卡片
- [ ] **6. 筛选**：筛选"模块=backend" → 只显示该模块卡片（清空筛选后恢复全部）
- [ ] **7. 统计一致**：统计条上的 P0 数量 = 列表中实际 P0 卡片数量（逐个数一遍）
- [ ] **8. 持久化**：`Ctrl+C` 杀掉后端进程重新 `npm start` → 所有数据仍在
